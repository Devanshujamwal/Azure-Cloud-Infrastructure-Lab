# Microsoft Azure Cloud Infrastructure Lab

**Azure VMs · VNets · NSGs · RBAC · Storage · Monitor · Log Analytics**

A hands-on academic Azure infrastructure project focused on compute, networking, access control, storage, and monitoring.

## What I worked on
- Windows and Linux virtual machines
- Virtual Networks and subnet concepts
- Network Security Groups
- RBAC and least-privilege access
- Azure Storage
- Azure Monitor and Log Analytics

## Troubleshooting approach
I separate cloud issues into resource state, network path, NSG rules, guest OS, permissions, and monitoring data before making changes.
